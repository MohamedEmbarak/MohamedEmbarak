## Open source

**[seoaudit](https://github.com/MohamedEmbarak/seoaudit)** — SEO analysis in one Python
command. It reports the **template, not the URLs**, so findings roll up to the file you
would actually edit, and it emits a remediation plan a coding agent can execute — each fix
carrying the command that re-verifies it.

**[Supreme Leader](https://github.com/MohamedEmbarak/Supreme-Leader)** — a Claude Code plugin
running a five-team agent organization where verification is **mechanical, not requested**:
hooks block a stated test result that doesn't reproduce, and refuse a fabricated import before
the file is written.

**[Supreme Leader Lite](https://github.com/MohamedEmbarak/SLL)** — the same enforcement with no
organization behind it. Three hooks, no agents.
